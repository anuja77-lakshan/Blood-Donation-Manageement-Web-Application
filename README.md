# 🩸 BloodLink - Blood Donation & Campaign Management System

BloodLink is a web-based application designed to bridge the gap between blood donors, local hospitals and campaign organizers. It streamlines the process of organizing blood donation camps, tracking live blood stock levels, managing emergency requests and coordinating community blood drives.


## 🚀 Key Features

* **User Authentication & Role Management:** Secure login and registration for donors and administrators.
* **Blood Camp Registration & Management:** Organizers can publish new blood donation drives with custom helpline numbers, dates, and times.
* **Interactive Leaflet Maps:** Integrated mapping to locate nearby blood donation camps and hospitals.
* **Real-time Blood Stock Dashboard:** Live visual indicators showing reserve levels for all blood groups (A+, B+, O+, AB+, A-, B-, O-, AB-).
* **Emergency Blood Requests:** Platform to post and review urgent blood requests for critical patients.


## 🛠️ Technologies Used

* **Frontend:** HTML5, CSS3, JavaScript, Leaflet.js (Interactive Maps), Font Awesome
* **Backend:** PHP (Server-side scripting)
* **Database:** MySQL (phpMyAdmin)
* **Version Control:** Git & GitHub
